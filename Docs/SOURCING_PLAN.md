# Plano de sourcing de assets — Prototype 01

## Direção recomendada

Para o primeiro protótipo visual, evitar misturar cinco estilos diferentes. A opção mais econômica e coerente é usar **Quaternius como família visual principal**, porque há personagens, roupas, animações, armas, props e cenários compatíveis entre si sob CC0.

## 1. Base dos personagens — recomendado

**Quaternius — Universal Base Characters**
https://quaternius.com/packs/universalbasecharacters.html

Uso:
- base humanoide do Guerreiro e Assassino;
- rig Humanoid;
- retarget de animações;
- personagens provisórios ou definitivos se a direção visual agradar.

Licença indicada pelo autor: CC0, inclusive uso comercial.

## 2. Roupas Guerreiro / Assassino — recomendado

**Quaternius — Modular Character Outfits - Fantasy**
https://quaternius.com/packs/modularcharacteroutfitsfantasy.html

Uso:
- Guerreiro: peças de armadura mais largas/pesadas;
- Assassino: peças leves, capa/hood se disponível;
- combinar partes sem trocar a base humanoide.

O pack é compatível com Universal Base Characters e Humanoid retargeting.

## 3. Animações — primeira escolha

**Quaternius — Universal Animation Library**
https://quaternius.com/packs/universalanimationlibrary.html

**Quaternius — Universal Animation Library 2**
https://quaternius.com/packs/universalanimationlibrary2.html

A segunda biblioteca inclui combos corpo a corpo e complementa a primeira.

Alternativa / complemento:

**Adobe Mixamo**
https://www.mixamo.com/

FAQ de licença:
https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html

Mixamo é útil para encontrar rapidamente animações específicas que não existirem na biblioteca escolhida.

## 4. Armas, poções, baús e props

**Quaternius — Fantasy Props MegaKit**
https://quaternius.com/packs/fantasypropsmegakit.html

Uso:
- espada;
- escudo;
- adagas;
- poções;
- baús/drop;
- objetos decorativos;
- pickups provisórios.

## 5. Arena / ruínas

**Quaternius — Medieval Village MegaKit**
https://quaternius.com/packs/medievalvillagemegakit.html

ou versão menor:

**Quaternius — Medieval Village Pack**
https://quaternius.com/packs/medievalvillage.html

Não montar uma vila completa. Extrair apenas pisos, pedras, pilares, paredes baixas e elementos que preservem leitura de combate.

Alternativa gratuita URP no Asset Store:

**FREE Slavic Medieval Environment Town Interior and exterior**
https://assetstore.unity.com/packages/3d/environments/fantasy/free-slavic-medieval-environment-town-interior-and-exterior-167010

## 6. VFX

Começar sem compra.

**Magic Effects FREE — Unity Asset Store**
https://assetstore.unity.com/packages/vfx/particles/spells/magic-effects-free-247933

Depois, caso falte qualidade/variedade:

**Stylized Vfx Fantasy Pack**
https://assetstore.unity.com/packages/vfx/stylized-vfx-fantasy-pack-350426

Os VFX comprados/prontos devem ser tratados como matéria-prima. Cor, escala, timing e duração serão adaptados aos eventos de combate do projeto.

## 7. UI

**Kenney — UI Pack**
https://kenney.nl/assets/ui-pack

**Kenney — UI Pack RPG Expansion**
https://kenney.nl/assets/ui-pack-rpg-expansion

Licença indicada: CC0.

## 8. Opção de personagem pronto no Unity Asset Store

Se quisermos testar uma estética diferente sem montar roupa modular:

**FREE Starter Pack - Sidekick Modular Characters by Synty**
https://assetstore.unity.com/packages/3d/characters/free-starter-pack-sidekick-modular-characters-by-synty-336970

Não misturar Synty e Quaternius no produto final sem harmonização visual. Escolher uma família principal depois do teste.

## Ordem de download recomendada

1. Não baixar nada até a cena de cápsulas funcionar.
2. Universal Base Characters.
3. Modular Character Outfits - Fantasy.
4. Universal Animation Library 1 e 2.
5. Fantasy Props MegaKit.
6. Medieval Village/ruínas.
7. Magic Effects FREE.
8. Kenney UI.

Essa ordem reduz o risco de gastar tempo importando arte antes de validar gameplay.
