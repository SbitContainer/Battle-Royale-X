# Battle Royale X — Combat Principles

## Core identity

Battle Royale X is a fast 2.5D competitive ARPG/Battle Royale where outcomes are driven primarily by execution, reading the opponent, positioning, defense, movement and ability interactions — not by level, gear rarity or early snowball.

## Continuous control — no hard crowd control

A central design rule is that players should keep control of their character during combat.

The prototype should not introduce traditional long hard-CC mechanics such as:

- long stuns;
- roots that remove movement for meaningful periods;
- silences that prevent the player from using the kit;
- long knock-ups;
- unavoidable chain-CC combos;
- attacks that lock an opponent until death.

Allowed feedback/control mechanisms are primarily **soft control**:

- knockback / displacement;
- recoil;
- very short micro-stagger used only to communicate impact;
- hit-stop measured in milliseconds;
- walls / barriers that change routes;
- zones that force repositioning;
- projectile denial;
- pressure that changes available options.

Rule of thumb:

> Control should change position, route, timing or options — not remove the player's ability to play.

## Reaction-first combat

Every meaningful offensive action should have at least two possible responses where practical, such as:

- dodge;
- guard;
- parry;
- clash;
- nullify;
- reflect;
- reposition;
- attack the incoming projectile;
- use terrain or a tactical consumable.

No ordinary attack or ultimate should be designed as an unavoidable instant kill.

## Skill expression

The game should reward:

1. mechanical execution;
2. timing;
3. aim and direction;
4. cooldown memory;
5. opponent reading;
6. ability-interaction knowledge;
7. dynamic variation swapping;
8. team synergy through physical/mechanical interactions rather than numeric buffs alone.

## Anti-snowball

Loot and kills should create tactical options, map control, information and consumable advantages. They should not create large permanent stat gaps.

Ability variants should mainly change behavior, not simply add raw damage percentages.
